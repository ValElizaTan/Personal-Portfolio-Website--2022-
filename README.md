# Personal Portfolio Website (2022)

My first personal portfolio website, built with plain HTML and CSS (plus a little JavaScript for the gallery) for the Web Development module (EGL144) at Nanyang Polytechnic. The pages follow designs I made in Adobe Illustrator for the companion design module (EGL162).

## Pages

| Page | Content |
|------|---------|
| **Home** (`index.html`) | Site logo, navigation menu, name and course introduction ("Infocomm & Media Engineering"). |
| **About Me** (`AboutMe.html`) | Short bio, the tools I use (Photoshop, Illustrator, JavaScript, C#, HTML, CSS) and my hobbies: Lego building, badminton and playing guitar. |
| **Portfolio** (`Portfolio.html`) | A 10-slide gallery with arrows and dots. It includes a Photoshop presentation deck, an Illustrator card deck, website mock-ups, and demo videos of my **Java Music Project** and **C# Snake Game**. Below it are a watercolour wolf painting, a metal art tooling piece from my CCA and a poster for my FIE assignment. |
| **Contact Me** (`ContactMe.html`) | Social links, an email link and a link to the feedback page. |
| **Phone & Feedback** (`Phone-Feedback.html`) | Contact number and a feedback form (name, 1–5 rating, mobile, email, comments). |

## Tech

- HTML5 and CSS3 (one stylesheet per page)
- Vanilla JavaScript for the slideshow and for pausing other videos when one starts playing

## Running it

No build step is needed. Open `index.html` in a browser.

## Notes

- The feedback form posts to a public echo test endpoint, which was used for the assignment demo.
- Social media icons link to the generic Facebook, Twitter and Instagram home pages.
- Some media files are large (the two demo videos are about 10 MB each). Consider compressing them or hosting the videos elsewhere before pushing to GitHub.
